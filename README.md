# ROUNDS — Isaac Addon

Отдельный аддон к «Round Settings»: 73 карты (46 The Binding of Isaac с настоящими механиками — лазеры, взрывы, орбитали, активки на Q/Y; 27 S.T.A.L.K.E.R.).

Установка: `RoundsIsaacAddon.dll` в `BepInEx/plugins/RoundsIsaacAddon/` (нужен основной мод).
Выключить: удалить DLL или `Enabled = false` в `BepInEx/config/com.dmah.roundssettings.isaac.cfg` (перезапуск игры; у всех игроков одинаково).
Сборка: `bash build.sh`.
